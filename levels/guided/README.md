# Guided Path

The Guided Path is the structured curriculum for people using GDB for the first
time. Exercises are ordered so that each one builds on commands introduced
earlier.

| Level | Focus | Status |
|-------|-------|--------|
| [00 - Basics](00-basics) | Build, run, inspect variables, step through functions | Complete |
| 01 - Breakpoints | Function, line, and conditional breakpoints | Planned |

Use `dojo list` for the live view, including which exercises you have finished.
